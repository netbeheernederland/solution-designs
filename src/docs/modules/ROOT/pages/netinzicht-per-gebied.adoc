== Reikwijdte

Het Energiedataportaal stelt een openbare dataset beschikbaar waarmee
ondernemers inzicht krijgen in capaciteitsschaarste op het elektriciteitsnet
per postcodegebied. De informatie is gebaseerd op de voeding vanuit
onderliggende onderstations en ondersteunt ondernemers bij locatie-,
uitbreidings- en investeringsbeslissingen.

== Dataservice

De gebruiksscenario's beschrijven niet het uitvalproces (_happy flow_), deze
stappen dienen apart beschreven en geïmplementeerd te worden.

=== Gebruiksscenario

Een externe partij verkrijgt toegang tot een openbaar beschikbare dataset
vanuit het Energiedataportaal voor hergebruik binnen eigen processen of
systemen.

.Gebruiksscenario
[d2,svg,theme=4]
----
shape: sequence_diagram

vars: {
  d2-config: {
    pad: 20
  }
}

Derde partij -> Energiedataportaal: "1. Raadpleegt beschikbare data"
Energiedataportaal -> Energiedataportaal: "2. Stelt dataset beschikbaar"
Derde partij -> Energiedataportaal: "3. Vraagt dataset op"
Energiedataportaal -> Derde partij: "4. Levert dataset"
Derde partij -> Derde partij: "5. Verwerkt en gebruikt data"
----

1. De derde partij raadpleegt het overzicht van beschikbare datasets op basis
   van een selectie van _dekkingsgebied_/_onderstation_;
2. De derde partij selecteert een relevante dataset;
3. De derde partij vraagt de geselecteerde dataset op;
4. Het Energiedataportaal levert de dataset aan de derde partij;
5. De derde partij verwerkt de ontvangen gegevens voor het beoogde gebruiksdoel.

=== Architectuur

Voor dit dataproduct wordt gebruik gemaakt van mens, proces en techniek
beschikbaar ten behoeve van de _NBNL Profile Group_.

== Dataset

Voor de informatiebehoefte van _Netinzicht per gebied_ worden de volgende
https://modellen.netbeheernederland.nl/solution-designs/use-cases#_onderwerpen[onderwerpen]
gebruikt:

[cols="1, 1, 2"]
|===
|Onderwerp |Profile |Opmerking

|Aanwezige transportcapaciteit
|Equipment
|Aanwezige transportcapaciteit wordt vanaf de invoedende `PowerTransformer`-s
voor het gevraagde `VoltageLevel` afgeleid.

|Connectiviteit (huidig net)
|Equipment
|`Substation`, `VoltageLevel` en `EnergyConsumer` zijn vereist voor de use
case.

|Locatie (postcode+huisnummer)
|Geographical Location
|`EnergyConsumer`-s worden op postcode6 geaggregeerd tot postcodegebied.

|Topologie
|Topology
|`TopologicalNode` is vereist voor de relatie `EnergyConsumer`/`VoltageLevel`.

|Voedingsgebied
|Equipment
|`Substation` op een `BaseVoltage` van 150/220 kV is het beginpunt van een
voedingsgebied.

|===
