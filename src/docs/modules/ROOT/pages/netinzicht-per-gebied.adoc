== Reikwijdte

Het Energiedataportaal stelt een openbare dataset beschikbaar waarmee
ondernemers inzicht krijgen in capaciteitsschaarste op het elektriciteitsnet
per postcodegebied. De informatie is gebaseerd op de voeding vanuit
onderliggende onderstations en ondersteunt ondernemers bij locatie-,
uitbreidings- en investeringsbeslissingen.

== Voorwaarden

Dit dataproduct wordt als _open data_ aangeboden.

== Beslissingen en aannames

*Beslissingen* zijn keuzes die zijn afgestemd met en akkoord bevonden door de
betrokkenen. *Aannames* zijn keuzes gemaakt door de solutionarchitect, maar nog
niet geaccordeerd. Indien een aanname geen beslissing teweeg brengt is een
aanpassing in het ontwerp noodzakelijk.
