== Reikwijdte

Dit document beschrijft de use cases en invulling van de
https://modellen.netbeheernederland.nl/data-products/information-models/nbnl-profile-group.html[NBNL
Profile Group]. De _NBNL Profile Group_ bestaat uit de volgende dataproducten
(_profiles_):

* https://modellen.netbeheernederland.nl/nbnl-equipment[Equipment] (EQ):
  defines the electrical equipment in the network model, including their
  technical characteristics and relationships
* https://modellen.netbeheernederland.nl/nbnl-asset[Asset] (AS): describes
  the physical assets owned or managed by the utility, including their
  identity, lifecycle, and management information
* https://modellen.netbeheernederland.nl/nbnl-operation[Operation] (OP):
  captures the real-time operational state and control information of the power
  system used for monitoring and running the network
* https://modellen.netbeheernederland.nl/nbnl-geographical-location[Geographical
  Location] (GL): provides the geographic position and spatial representation
  of network assets and equipment on maps or geographic systems
* https://modellen.netbeheernederland.nl/nbnl-topology[Topology] (TP):
  represents an abstraction of the current electrical connectivity of the
  network for a specific use case

== Use cases

Use cases brengen <<_onderwerpen>> samen tot een specifieke invulling van
functionele eisen vanuit een werkgroep, voor een specifiek spanningsniveau.
Voor _Buurtnet_ is b.v. connectiviteit van het laagspanningsnet (LS) vereist.
Ook hoeven, afhankelijk van gemaakte afspraken, niet alle CIM-classes
geïmplementeerd te zijn om het onderwerp ingevuld te hebben. *Dikgedrukte*
onderwerpen kennen een hoge mate van onzekerheid of zijn nog niet in de _NBNL
Profile Group_ opgenomen.
