* Netbeheerders leveren via het eigen _Dataloket_ _JSON-LD_ (RDF) onder de
  _NBNL Profile Group_;
* _JSON-LD_ wordt aangeleverd bij _EDSN_ (Broker) via de _File Gateway_;
* _EDSN_ verwerkt de aangeleverde profiles tot een dataproduct geschikt voor
  afname door een _Consumer_, via de processen _Extract_ en _Load_;
* het dataproduct voor de _Consumer_ wordt als _JSON-LD_ (RDF) via het
  _Energiedataportaal_, onder het model beheerd door _Team Semantiek_, NBNL.
